# Asset catalog
The client run on CLI, asks the watched directory toshow him All the asset names hosted on the server,  
and then the client checks if the name of its assetalready exists in the watched directory - exist inserver.  
If it already exists - the customer will change the name of his asset to unique name.  
if the name of his asset is unique and not saved yet - he can upload his asset to the server.  
A copy of the asset name will remain in the watched directory.
